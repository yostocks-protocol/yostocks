Raw notes (facts, timestamps, evidence) collected while building. The DX Report itself is written by the team, not generated from this file.

**Onboarding:** hackathon page opened ~09:40 UTC; first successful RWA Data call ~10:00 UTC (~20 min, of which most was the ISP DNS block + WAF on llms-full.txt). First Agentic Wallet quote ~10:55 UTC after CLI PATH issue + sign-in.

## 2026-09-24

- **09:45 · web3.binance.com / developers.binance.com (Indonesia, ISP Biznet)** — DNS is RPZ-hijacked to a "Safesurf" block page (202.169.44.80); even `@1.1.1.1` is intercepted. TLS error shows as "certificate has expired" (block page serves an old cert), which misleads you into debugging Binance's cert. Needed Cloudflare WARP. Impact: ~15 min lost; ID builders will hit this on day 1. Suggest: mirror docs on github/bnbchain.org and mention it in the hackathon resources.
- **09:50 · `https://web3.binance.com/en/dev-docs/llms-full.txt`** — returns `HTTP 202`, empty body, `x-amzn-waf-action: challenge` (AWS WAF JS challenge) to curl, even over WARP. The "LLM-format docs" can't be fetched by the LLM agents/tools they're meant for. Workaround: `binance/binance-skills-hub` repo SKILL.md files.
- **10:00 · skills-hub `binance-tokenized-securities-info/SKILL.md`** — says `type=1` Ondo is "currently the only supported tokenized stock provider". Actual `stock/detail/list/ai` response on BSC (chainId 56): type 1 Ondo `…on` (458), type 2 xStocks `…x` (128), type 3 bStocks `…B` (80), type 4 (4: xKLSH, xOPAI, xSPCX, pPOLY), type 9 (1: BNC4). Types 2–9 undocumented; had to infer from symbol suffixes.
- **10:00 · same endpoint** — undocumented response fields: `assetType`, `d` (decimals?), `lastUpdateTime`, and for bStocks `cs` (e.g. `NVDABUSDT`, looks like a CEX pair) and `asset`. Other chains present too: `CT_501` (Solana?), `4663`, `8453` (Base) — none documented.
- **10:00 · `rwa/market/status/ai`** — undocumented `marketStatus` and `offhours{}` object. During `premarket` it returned `nextOpen=13:31Z` and `nextClose=13:29Z` (close before open while open) — semantics unclear.
- **10:05 · `rwa/dynamic/ai` (v2) for xStocks/bStocks** — `totalHolders` is null for xStocks and bStocks (only Ondo populated); `stockInfo.price` null for bStocks. xStocks `tokenInfo.price` far from reference: META 572.44 vs 723.60 (−21%), MSTR 138.86 vs 157.11 (−12%) while Ondo/bStocks stay within 0.1%. Unclear whether stale price, multiplier not applied, or real DEX price. No field says price source/timestamp.
- **10:20 · liquidity reality check (DexScreener, BSC)** — bStocks has deep PancakeSwap USDT pools (NVDAB $3.5M liq, TSLAB $2.0M, MSTRB $479k, METAB $304k). xStocks on BSC: no pools for METAx/MSTRx/NVDAx, TSLAx pool = $9 liquidity. - **10:40 · `npm i -g @binance/agentic-wallet` (1.10.0)** — install warns `allow-scripts` blocked `@github/keytar` install script (npm 11 default); `baw` lands in the npm global prefix bin which wasn't on PATH (pnpm-managed node) → `command not found: baw`. - **10:45 · `baw market-order quote`** — requires sign-in (`NOT_LOGGED_IN`) even for a read-only quote. A price-comparison agent can't quote without a user wallet session; a public quote endpoint would help.
- **10:50 · sign-in** — `auth signin` returned `urlForWeb=https://app.binance.com/uni-qr/...`, docs example shows `https://web3.binance.com/en/agent-login?...`. Flow itself smooth (<1 min).
- **10:55 · quotes, 100 USDT → token, BSC** — Ondo (`…on`, no meaningful AMM pool) IS executable via the Binance router at ~reference price (NVDAon $222.52/share, default slippage 0.5%); bStocks similar (NVDAB $222.55, default slippage 1%). xStocks: `SERVICE_ERROR code 100 "No liquidity available"` for NVDAx/METAx/TSLAx — **but MSTRx returned `success:true` with toCoinAmount≈0** (effective $4.16B/share). A naive agent that trusts `success` would burn 100 USDT. Quote response has no price-impact / min-received / route field to catch this. Code `100` + name `SERVICE_ERROR` for a normal "no liquidity" condition is too generic.
- **11:25 · quote size sensitivity** — NVDA at 5 USDT: Ondo +0.43% vs reference, bStocks −0.09%. At 100 USDT both within ~0.1%. Small first-time buys pay noticeably more on Ondo's route; nothing in the quote response (no fee/price-impact breakdown) explains why.
- **11:40 · BNB Agent Studio (docs.bnbchain.org/developer-kit/bnbchain-studio/, `@bnbagent/studio-cli` 0.0.14)** — Studio agents are *seller* agents (sell work via x402/B402 or ERC-8183 escrow). Bundled skill `selling-via-b402.md` itself says: "Do not claim current mainnet readiness until polling is implemented" (`@bnb-chain/b402@0.2.1` doesn't poll async `/settle`). ERC-8004/8183 contracts are deployed on mainnet (ARCHITECTURE.md).
