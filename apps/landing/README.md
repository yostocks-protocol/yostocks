# yostocks landing

Astro + TypeScript, static. Design based on the MotionSites "Cybersecurity Hero" prompt, recoloured to the YO logo.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # astro check + static build to dist/
```

Content (steps, features, mainnet txs, findings) lives in `src/data/content.ts`. Deployed by Coolify from `apps/landing/Dockerfile`.
